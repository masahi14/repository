# 操作マニュアル(スタッフ向け)

## これは何?

カルテ入力ソフトの画面の隅に小さなボタンパネルが表示されます。よく使う処置コード・指導文言のセットを、ボタン1つでまとめて入力できるツールです。

## 使い方

1. いつも通り、カルテ入力ソフトの入力欄をクリックしてカーソルを合わせます。
2. パネルの中から、入力したいセットのボタンを1回クリックします。
3. 該当するコードが自動的に連続して入力されます。
4. 入力が終わったら、実際の診療内容に合わせて **その場で確認・修正** してください。

## 大事な注意点

- **ボタンを押している間は、他の操作をしないでください。** 自動入力が終わるまで少し待ちます(終わるとボタンが再び押せる状態に戻ります)。
- 一部のセット(歯科衛生実地指導、フッ素、義歯など)は、**当てはまらない項目も一緒に入力されます**。診療内容に合わないものは、その場で手動で削除してください。
- **PMTC・フルマウスレントゲンコメントの2つのセットは、処置コードのみが自動入力されます。** その後に続けて開く選択画面(担当衛生士名、X線読影コメント等)は自動化していないため、必ず手動で選択・入力してください。
- 血圧・脈拍・SpO2・実地指導時間など、**実際に測定・実施した数値や時刻は、必ず手入力してください**。このツールはそれらの数値を自動生成しません(意図的にそうしています)。
- 歯周病患者画像活用指導料セットの文章中の「●●」の部分は、実際の歯の部位に置き換えて手入力してください。

## パネルの位置を動かしたい

パネルはドラッグして好きな位置に移動できます。次に開いたときも同じ位置に表示されます。

## うまく動かないとき

- コードが正しい欄に入力されない場合は、まず入力欄にカーソルが合っているか確認してください。
- それでも改善しない場合は、院内のIT担当(桐生さん)にご連絡ください。
