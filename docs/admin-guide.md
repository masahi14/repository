# 管理者向けガイド(桐生さん向け)

このドキュメントは、`config/sets.json` の内容を編集・追加する担当者向けの説明です。プログラムのコードを一切触らずに、セットの中身を追加・修正できます。

## 編集してよいファイル

- `config/sets.json` — セットの中身(コード・並び順・ランダム抽出の個数)
- `config/settings.json` — キー送信の待機時間、テストモードのON/OFF

**現状 `config/settings.json` の `test_mode` は `false` になっています(6セットすべて実機での動作確認が完了したため)。** 新しいセットを追加したり既存のセットを変更したりした場合は、下記「変更後の確認方法」に沿って `test_mode` を一時的に `true` に戻し、動作確認が済んでから再び `false` に戻してください。

`src/` フォルダの中身(`.ahk`ファイル)は触らないでください。

## `sets.json` の書き方

### パターンA: 決まった順番で全部入力する(固定フルセット)

```json
{
  "id": "pmtc",
  "label": "PMTC",
  "pattern": "fixed_sequence",
  "items": [
    { "code": "40186" },
    { "code": "12345" }
  ]
}
```

- `id`: 半角英数字のみの内部識別子。他のセットと重複しないようにしてください。
- `label`: パネルのボタンに表示される名前。日本語で自由に書けます。
- `items`: 上から順番に入力される項目の一覧です。順番を変えたい場合は、この配列の順番を入れ替えてください。

### パターンB: プールからランダムに選んで入力する

現在使っているセットはすべてパターンAですが、仕組みとしては以下のように書けます(参考例)。

```json
{
  "id": "example_random_set",
  "label": "サンプル",
  "pattern": "random_pool",
  "pick_count": 5,
  "pool": ["10001", "10002", "10003", "10004", "10005",
           "10006", "10007", "10008", "10009", "10010",
           "10011", "10012", "10013", "10014", "10015"]
}
```

- `pick_count`: プールから何個ランダムに選ぶかの数です。この数値だけを書き換えれば個数を変更できます。
- `pool`: 選択肢となる5桁コードを全部並べてください。

### 「コード入力後、値は空欄のまま残す」項目

実地指導時間のように、コード確定後に実際の時刻・数値を人が手入力する必要がある項目には `then: "leave_blank_manual_entry"` を付けてください。

```json
{ "code": "43771", "then": "leave_blank_manual_entry" }
```

**注意**: この項目に数値や時刻の値を追加で書き込むことはできません(意図的にできない仕組みになっています)。実測していない数値をカルテに自動入力することは、記録の正確性・診療報酬請求の正当性の観点から行いません。

### 5桁コードが存在しない項目(`menu_path`)

フルマウスレントゲンコメントの一部所見や義歯セットの指導文言など、メーカー確認の結果5桁コードが存在しない項目については、`code` の代わりに `menu_path` というキー操作の列を書きます。

```json
{ "menu_path": ["+{F1}", "{F2}", "{Down}", "{Down}", "{Enter}"], "note": "中等度歯槽骨吸収(+)" }
```

これは「処置選択表」画面(`Shift+F1` → `F2`)を開き、矢印キーでメニューをたどってEnterで確定する一連のキー操作です。**この部分は桐生さん・院長が手で書く必要はありません。** 処置選択表の各階層のスクリーンショットをClaude(このプロジェクトのAIアシスタント)に送っていただければ、必要なキー操作の回数を計算して代わりに記入・コミットします。書き方を変えたい場合や動きがおかしい場合はご相談ください。

## 新しいセットを追加したい場合

`sets.json` の `sets` 配列の末尾に、上記のパターンA・パターンBのいずれかの形式でオブジェクトを追加してください。パネルのボタンは自動的に増えます。

## 変更後の確認方法

1. `config/settings.json` の `test_mode` を `true` にする。
2. ツールを再起動(または右クリックメニューの「設定を再読み込み」)。
3. 追加・変更したセットのボタンを押す。
4. `%LOCALAPPDATA%\DentalKartePanel\logs\` の中にあるログファイルを開き、意図した順番・個数の項目が記録されているか確認する。
5. 問題なければ `test_mode` を `false` に戻す。

## 書き方を間違えるとどうなるか

`sets.json` の形式が正しくない場合(JSONの文法エラー、許可されていない項目名を使った場合など)、ツールは起動時にエラーメッセージを表示し、**直前まで正常に動いていた設定に自動的に戻ります**。カルテ入力中に急にツールが使えなくなることは基本的にありません。エラーメッセージが出た場合は、直前の変更内容を見直してください。

## 20台への反映方法

共有フォルダ(`\\FILESERVER\dental-tools\karte-panel\` 等、実際のパスは導入時に決定)の `config/sets.json` を書き換えれば、各パソコンは次回ログオン時に自動的に最新の設定を取り込みます。個別にパソコンを回って設定する必要はありません。
