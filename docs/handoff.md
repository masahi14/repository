## 最重要の安全制約(絶対に忘れてはいけない)

**本ツールが自動入力してよいのは、臨床的な事実に基づいてスタッフが選ぶ処置コード・定型文言・メニュー選択のみ。測定値・時刻など事実を表す数値は絶対に自動生成しない。** これは今後も新しい要望が来るたびに必ず確認すること。コード上も `src/lib/InputEngine.ahk` の `_HandleLeaveBlankManualEntry()` や `config/sets.schema.json` のフィールド制限で多層的に担保している(詳細は `docs/architecture.md`)。方法2(メニュー選択、後述)も、あらかじめ決められた固定のキー操作を再生するだけで、画面を読み取って動的に判断したり数値を入力したりすることは一切ない。

## 【最重要】今回のセッションで判明した、カルテソフトのメニュー操作の介み

これは次に残り4セットのTODOを埋める際にも必須の知識です。

### 入力方法は2種類

- **方法1(コード入力)**: 入力欄にフォーカスがある状態で5桁の数字コードを入力しEnter。`config/sets.json` の項目に `code` を持たせる。
- **方法2(メニュー選択)**: 5桁コードが存在しない項目はこちら。`config/sets.json` の項目に `menu_path`(AutoHotkey Send形式のキー配列)を持たせる。

### 方法2の具体的な操作手順(今回発見・実機検証済み)

1. **`Shift+F4` → `F5`** を押すと「カスタムコメント選択」という、院内の全コメントグループを1つの巨大なリストとして表示する画面が開く(グループ数は50以上あり、スクロールが必要)。
2. このリストは**複数選択(マルチセレクト)対応**で、各行の左に表示された数字/アルファベット(1〜9, A〜G)を押すとその行がハイライトされ選択状態になる(カーソルの移動とは独立した操作)。**画面に見えている行の数字/アルファベットを押すだけでよく、下矢印キーで移動してから押す必要はない。**
3. 複数のグループを選択したら **Enter** を押す。すると選択したグループの**1つ目のサブメニュー**(実際の文言リスト)が開く。
4. サブメニュー内でも同様に、見えている行の数字/アルファベットを押して複数選択し、**Enter**を押す。すると自動的に**次に選択したグループのサブメニュー**が開く(閉じずに連鎖する)。
5. **最後に選択したグループのサブメニューでEnterを押すと、画面が閉じてカルテの入力欄に戻る**(この時点でカルテに文言が反映される)。

### 下矢印キーでスクロールする際の重要な規則(実機検証で確定)

- リストが開いた直後、カーソルは1番上(絶対位畲1)にある。
- **下矢印キーを1回押すごとにカーソルは1つ下に進む**。
- 見えている行の範囲(ウィンドウ)は、リストによって高さが違う(16行のものと13行のものを確認済み)。**カーソルが最初のページ(1〜16番目、または1〜13番目)の中にいる間は、ウィンドウはスクロールしない。**
- カーソルが最初のページを超えて移動すると、ウィンドウはスクロールし、**スクロール後は常にカーソルが表示ウィンドウの一番下の行(16行タイプなら"G"、 13行タイプなら最後の文字)に来る**。つまり、絶対位置Nの項目を選びたい場合、シンプルに「下矢印キーを (N-1) 回押してから、そのとき一番下に表示されている文字キーを押す」で選択できる(**実機で複数回検証済みの確実な計算式**)。
- **数字/アルファベットで選択する操作(トグル)自体は下矢印キーのカウントに影響しない**。つまり「3を押して選択」→「その後下矢印を39回押す」は、「3を押さずに下矢印を39回押した場合」と全く同じ位置に到達する。この性質を利用し、複数選択する際は「必要な位置まで下矢印で進みながら、通過中に見えたものは都度その場で数字/アルファベットキーで選択していく」という設計をしている。

### 5桁コードが、実は「1個の処置」ではなく「候補メニューを開くトリガー」であるケースがある

例: 義歯セットの `40177` を送信すると、単に1つの処置が確定するだけでなく、**「義歯調整内容」という小窓が自動で開く**(これを利用し、コード送信の直後にメニュー選択の `menu_path` を続けて実行する設計にしている。`config/sets.json` の `denture` セットを参照)。**注意**: 同じ小窓は `46007` を送信した場合にも開くが、そちらは指導文言とは無関係なので `denture` セットからは意図的に除外し、自動送信していない(ドクターが必要な時に別途手入力)。今後、他のコードでも同様に「実は候補メニューを開くだけ」というケースがないか、注意深く確認すること。

### 方法2の項目が複数のグループにまたがって見つかることがある

同じ内容(似た文言)が、異なるグループに重複して存在することがある(例: 「う窝〜歯髓腔に及ぶ透過像」がPerグループとPulグループの両方にあった)。またパンフレットなど実際の現場資料と照合すると、当初のメモ書きの文言と実際の文言が微妙に違うことがあるため、**可能であれば実際に患者へ渡している資料(パンフレット等)と照合するのが最も確実**(義歯セットではこの方法で全項目を確定できた)。
