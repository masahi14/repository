# 1台だけで試す場合の手順(パイロットテスト用)

20台への本展開の前に、まず1台だけでビルド〜スタートアップ登録までを試すための簡易手順です。共有フォルダは使わず、そのPCのローカルフォルダだけで完結させます。うまくいったら `deploy/deploy-readme.md` の本番手順(共有フォルダ経由)に進んでください。

## 事前確認

- そのPCに **AutoHotkey v2** がインストールされていること(https://www.autohotkey.com/ から「Download」→「AutoHotkey v2」のフルインストーラを入れれば、ビルドに必要な `Ahk2Exe.exe` も一緒に入ります)。これまでの実機検証で `.ahk` ファイルを直接動かしていたPCであれば、すでに入っているはずです。
- リポジトリ(このプログラム一式)の最新版がそのPC上にあること。

## 1. ビルドする

1. そのPCで PowerShell を開く(スタートメニューで「PowerShell」と検索)。
2. リポジトリのフォルダに移動する。例:
   ```
   cd C:\Users\XXXX\repository
   ```
3. 次のコマンドを実行する:
   ```
   powershell -ExecutionPolicy Bypass -File build\build.ps1
   ```
4. 緑色で「ビルド完了」と表示されれば成功。`dist` フォルダの中に `DentalKartePanel.exe` と `config` フォルダができています。

   - `Ahk2Exe.exe が見つかりません` というエラーが出た場合は、AutoHotkey v2 のフルインストーラを入れ直してください(Ahk2Exeはコンパイラの本体で、通常版のインストールに含まれています)。
   - `静的安全チェックに失敗した` というエラーが出た場合は、コード側の問題の可能性があるため、そこで止めて相談してください。

## 2. まずはビルドしたexeを直接動かして確認する

共有フォルダやスタートアップ登録の前に、ビルドしたexe自体が今まで通り動くかをまず確認します。

1. `dist\DentalKartePanel.exe` をダブルクリックして起動する。
2. これまでの実機検証と同じように、練習用カルテ番号でボタンを押して動作確認する。
3. 問題なければ次に進む。

## 3. 配置先フォルダを決める(今回は1台だけなのでローカルでよい)

本番の20台展開では実際の共有フォルダ(`\\FILESERVER\...` など)を使いますが、1台だけの今回のテストでは、そのPCの中の適当なフォルダで構いません。例:

```
C:\DentalKartePanelTest\dist
```

`dist` フォルダの中身(`DentalKartePanel.exe` と `config` フォルダ)をこのテスト用フォルダにコピーしてください。

## 4. スタートアップ登録を試す

1. 同じ PowerShell で、次のコマンドを実行する(`-SharedDistPath` には手順3で決めたフォルダを指定):
   ```
   powershell -ExecutionPolicy Bypass -File deploy\install-startup.ps1 -SharedDistPath "C:\DentalKartePanelTest\dist"
   ```
2. 「スタートアップ登録が完了しました」と表示されれば成功。
3. すぐに試したい場合は、画面に表示されたコマンド(`powershell -File ... -SourceDir ...`)をそのままコピーしてPowerShellに貼り付けて実行するか、一度ログオフして再度ログオンしてください。ログオン時に自動的にパネルが起動すれば成功です。
4. スタートアップフォルダにショートカットができているかは、`Win+R` を押して `shell:startup` と入力してEnterを押すと確認できます(`DentalKartePanel.lnk` があればOK)。

## 5. 設定(sets.json)を書き換えたときの反映確認

1. 手順3のテスト用フォルダ(`C:\DentalKartePanelTest\dist\config\sets.json`)を直接編集する。
2. パネルのトレイアイコンを右クリックして「設定を再読み込み」を選ぶか、ツールを再起動する。
3. 意図通りに反映されているか確認する。

## うまくいかないとき

- **トレイアイコンが表示されない**: 前回までの実機検証でも見つかっている既知の未解決の現象です。ツール自体の動作(ボタンを押しての自動入力)には影響しないため、気にせず進めて問題ありません。
- **exeがウイルス対策ソフトにブロックされる**: そのPCのウイルス対策ソフトの警告・隔離ログを確認してください。20台展開時には、この許可リスト登録を桐生さんに依頼する予定です。
- 上記以外で動かない場合は、エラーメッセージ・状況をそのままClaudeに伝えてください。

## この1台テストがうまくいったら

`deploy/deploy-readme.md` に沿って、実際の共有フォルダを使った本番の展開手順(20台分)に進みます。その際は改めて桐生さんへの連絡・依頼(共有フォルダのパス確定、ウイルス対策ソフトの許可リスト登録など)が必要になります(`docs/kirisawa-rollout-request.md` を参照)。
