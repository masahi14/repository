# 判定の仕様(補助列・数式・テスト)

数式の生成元: `scripts/build_extraction.py`(`hyg_helpers` / `dr_helpers`)。
独立モデル(数式とは別の書き方): `scripts/verify_extraction.py`(`model_hyg` / `model_dr`)。
仕様を変えるときは、この2つと本書を同時に直し、`selftest` を通す。

## 抽出先シートの構造(共通)

| 位置 | 内容 |
|---|---|
| A1 | 注記(衛生士: 再確認の注記 / ドクター: 除外条件の説明) |
| A2 / B2 | 「抽出基準日」/ 基準日(衛生士シートが入力。ドクターシートは参照) |
| D2 | 件数サマリー(確定 n 名 / 要確認 m 名) |
| 3行目 | 見出し(固定・フィルター付き) |
| 4〜303行 | 一覧(最大300人分。患者一覧の2〜301行に対応) |
| P〜AD列(非表示) | 抽出キーと補助列(下表)。2〜301行が患者一覧の同じ行番号に対応 |

- `P{n}` 抽出キー: 確定=`n`、要確認=`n+1000`、対象外=`""`。
- `Q{4+k-1}` = `MOD(SMALL(P2:P301, k), 1000)` = 患者一覧の行番号。一覧の各セルは `INDEX(患者一覧!列:列, $Q)`。空セルが0になるのを避けるため `IF(INDEX(..)="","",INDEX(..))` の形。
- 確定の患者が先、要確認の患者が後(各グループ内は患者一覧の順)。
- 要確認の理由は `AD` 列で作り、一覧の右端の列は `INDEX($AD:$AD,$Q)` で表示。

## 補助列

### 歯科衛生士治療

| 列 | 意味 |
|---|---|
| R | 対象患者(患者IDあり・状態≠終了)=1 |
| S | ドクター最終診療日の状態: `blank` / `invalid` / `future`(>基準日) / `ok` |
| T | 衛生士最終診療日 > 基準日 |
| U | 口腔機能低下症の最終検査日 > 基準日 |
| V | 介護保険: `U`=利用中 / `N`=未利用 / `?`=空欄・不明 |
| W | 衛生士次回予定: `T`=定期検診 / `O`=マスタの定期検診以外 / `?`=空欄・不明表記 |
| X, Y | 取り得る期限の月数の最短・最長(下表) |
| Z | 患者ID重複 |
| AA, AB | ドクター最終診療日が最短/最長の月数の期限内(基準日 ≦ EDATE)か |
| AC | 区分 `T`(確定)/`C`(要確認)/空(対象外) |
| AD | 要確認の理由 |

月数の最短(X)・最長(Y):

| 介護保険 | 衛生士次回予定 | X | Y |
|---|---|---|---|
| U | (任意) | 3 | 3 |
| N | T | 2 | 2 |
| N | O | 1 | 1 |
| N | ? | 1 | 2 |
| ? | T | 2 | 3 |
| ? | O | 1 | 3 |
| ? | ? | 1 | 3 |

区分: `S≠ok` または `AA≠AB`(結果が割れる)または `T/U/Z=1` → `C`。それ以外で `AA=1` → `T`。`AA=AB=0` → 対象外。

### ドクター治療

| 列 | 意味 |
|---|---|
| R | 対象患者 |
| S | 検査日の状態: `blank` / `invalid` / `future` / `ok` |
| T | ドクター次回予定: `Y`=「ドクター診察・治療なし」/ `N`=マスタの他の選択肢 / `?`=空欄・不明表記 |
| U | 検査から3か月未満(基準日 < EDATE(検査日,3)): `T` / `F` / `?` |
| V | CR・抜歯・義歯のいずれかに記録あり |
| W | 患者ID重複 |
| X | 除外条件に該当(`T=Y` かつ `U=T`) |
| Y | 除外されないことが確定(`T=N` または `U=F`) |
| Z | 判断できない(X=0 かつ Y=0) |
| AA | 「治療なし」なのに進捗の記録がある(`T=Y` かつ V=1) |
| AB | 検査日 > 基準日 |
| AC | 区分 `T` / `C` / 空 |
| AD | 要確認の理由 |

区分: `Z/AA/AB/W` のどれかが1 → `C`。それ以外で X=1 → 対象外(除外)、Y=1 → `T`。

## テスト一覧(`verify_extraction.py selftest`)

- ランダム: 約250人 × 4ケース(基準日 2026-10-31 / 11-01 / 11-02)。期限の前後±1日、空欄、無効日付(文字列・1900/01/02)、基準日より後、不明表記(「定期健診」「介護あり」)、前後空白、ID重複、状態=終了を含む。
- 名前付きシナリオ(18件・期限当日/翌日、月末、ちょうど3か月、①だけ/②だけ、空欄、進捗記録、基準日より後、状態=終了)。
- 判定はシート上の実表示(確定/要確認/非表示)で確認する。
