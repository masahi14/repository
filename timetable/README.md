# 訪問歯科タイムテーブル作成ツール（v1）

1施設・午前/午後単位で、訪問診療のタイムテーブルを決定的ロジック（AI文章生成に依存しない）で
作成するツールです。ビルド不要。`index.html` をブラウザで開くだけで使えます。

## 使い方
1. `timetable/index.html` をブラウザで開く
2. 「施設を選ぶ」でよく使う施設（養護老人ホーム潮来／ハートワン潮来）を選ぶと施設名が自動入力され、
   その施設の介護保険の傾向（例：ハートワン潮来は基本全員介護併用）がヒントとして表示される。
   一覧にない施設は「＋別の施設名を入力」を選んで直接入力する
3. 日付・午前/午後・開始時刻・Dr/DH名（カンマ区切りで複数可）を入力
4. 患者を「＋ 患者を追加」で追加し、介護保険の有無（あり/なし）・区分（Drのみ/DHのみ/両方）・担当者・
   （両方の場合）Dr→DH or DH→Drの順序を設定
   - 短時間処置（抜糸・チェックのみ等）はDr/DH時間上書き欄に分数を入れると、
     通常ルール（Dr21-23分・DH20-22分等）を無視してその時間で確定する
   - 施設相談（Drのみの短時間対応）は「＋ 施設相談を追加」で追加する。Drのみ・時間欄(目安5分)が
     自動入力された状態になるので、実際の時間（目安3〜5分、長くて10分）に書き換える。時間を
     空欄のまま作成すると「未入力のため通常のDr処置時間で計算されています」と警告が出る
4. 訪問入力欄（算定項目）は「＋項目を追加」で項目名・人数の見方・今回の値（人数区分／点数など）を
   一覧形式で手入力する（自動計算はしない）。施設別入力ルール欄も同様に手入力メモ
5. 「タイムテーブルを作成」をクリックすると、A4横1枚を想定した印刷用シートが表示される
   - ヘッダー（施設名・日付・予定時間・新患数・保険メモ・Dr/DH/補助DH）
   - 患者別タイムテーブル（患者ごとにDr/DH時間を横並び表示）
   - 訪問入力（手入力メモをそのまま表示）
   - 厳重チェック（Dr・DH別の患者間時間差分。監査と同じ計算を再利用して表示）
   - 施設別入力ルール（手入力メモをそのまま表示）
   - 最終監査結果（🟢OK／🟡要確認／🔴エラー）
6. 「印刷 / PDF」でA4横に印刷（ブラウザの印刷機能を使用。画像生成AIは使用しない）

## 実装方針
- `logic.js`：時間計算（generateSchedule）と、生成ロジックとは別コードパスで
  出力結果だけを再検証する独立監査（auditSchedule）。DOM非依存で `node timetable/logic.test.js`
  でテスト可能。`groupByStaffSorted`/`computeGaps` は監査の内部計算と、厳重チェック欄の
  表示の両方から使う共通ロジック。
- `app.js`：画面制御のみ。時間計算・監査ロジックは持たない。
- 監査A〜D（患者単位のDr/DH重複、Dr単位・DH単位の重複再計算、患者ID二重登録）を実装済み。
- 監査E〜H（算定・保険区分・根拠資料との照合）は、患者マスター・施設マスター・
  「確認済みルール」化された根拠資料データが未整備のため未実装（次フェーズ）。
- 訪問入力・施設別入力ルールのパネルは、根拠資料（歯科点数表の解釈）がまだ
  「院内未確認」ステータスのため、自動判定・自動計算はせず手入力メモの表示のみに
  している。院内確認後、確認済みルールとして登録してから自動化する。

## 既知のスコープ外（次フェーズ）
- 患者マスター／施設マスター／スタッフマスターとの連携（現状は都度入力）
- 算定区分・人数区分の自動判定（現状は手入力メモ表示のみ）
- 根拠資料の登録・確認ステータス管理
- 複数施設をまたぐ1日通しのタイムテーブル・施設間移動時間の充足確認（監査E）
